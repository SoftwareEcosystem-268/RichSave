## Reflection

แม้ทีม Alpha จะสามารถพัฒนา Web Application “RichSave” ได้สำเร็จตามเป้าหมาย แต่ feedback จากการสัมภาษณ์ครั้งนี้ทำให้ทีมเข้าใจว่า การเรียนในรายวิชา Software Ecosystem ไม่ได้มีเป้าหมายเพียงแค่การสร้างระบบให้เสร็จเท่านั้น แต่คือการเรียนรู้การทำงานร่วมกันภายใน ecosystem ของการพัฒนา software จริง ทั้งการสื่อสาร การแบ่ง responsibility การจัดการ workflow และการแก้ปัญหาที่เกิดขึ้นระหว่างการทำงานของแต่ละ role ภายในทีม ซึ่งหลายปัญหาที่เกิดขึ้นระหว่างการพัฒนา เช่น การ merge code, การรอ environment สำหรับ testing หรือการจัดการ repository เป็นสิ่งที่ทำให้ทีมได้เห็นภาพของการทำงานจริงมากกว่าการเรียนจากทฤษฎีเพียงอย่างเดียว

ตลอดการทำโปรเจกต์ ทีมได้เรียนรู้ว่าการเป็น software engineer ที่ดี ไม่ได้วัดจากเพียงจำนวน feature หรือ commit บน GitHub แต่ยังรวมถึงความสามารถในการทำงานร่วมกับผู้อื่น การรับฟัง feedback และการปรับปรุง workflow อย่างต่อเนื่อง แม้จะมีข้อผิดพลาดเกิดขึ้นระหว่างทาง แต่ feedback จากอาจารย์ช่วยให้ทีมมองเห็นจุดที่ต้องพัฒนา และทำให้สมาชิกทุกคนเติบโตขึ้นทั้งในด้าน technical skill, teamwork และความเข้าใจเกี่ยวกับ software development process ซึ่งเป็นประสบการณ์สำคัญที่ทีมสามารถนำไปต่อยอดในการทำงานจริงในอนาคตได้
