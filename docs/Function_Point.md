## Value Adjustment Factor (VAF)

### หลักการประเมิน
ใช้ระบบคะแนน 0-5 สำหรับแต่ละปัจจัย
- **0** = ไม่มีอิทธิพล / ไม่เกี่ยวข้อง
- **1** = อิทธิพลน้อย
- **2** = อิทธิพลปานกลาง
- **3** = อิทธิพลมาก
- **4** = อิทธิพลมากเป็นพิเศษ
- **5** = อิทธิพลอย่างมาก

### ปัจจัยด้านการสื่อสารข้อมูล (Data Communications)

| ปัจจัย | รายละเอียด | คะแนน |
|:---|:---|:---:|
| 1. ระบบใช้สื่อสารข้อมูลระหว่างกันอย่างไร | แอปสื่อสารกับ Backend, Email API (Resend), Map API | **3** |

**คะแนนรวมกลุ่มที่ 1:** **3**

## สรุป VAF

| หัวข้อ | คะแนน |
|:---|:---:|
| รวมคะแนนทั้งหมด (Total Degree of Influence - TDI) | **27** |
| สูตรคำนวณ VAF | VAF = 0.65 + (TDI / 100) |
| คำนวณ | VAF = 0.65 + (27 / 100) = 0.65 + 0.27 = **0.92** |

---

## คำนวณ Adjusted Function Points (AFP)

| สูตร | คำนวณ |
|:---|:---:|
| AFP = UFP × VAF | AFP = 113 × 0.92 = **103.96 ≈ 104 FP** |

### ขนาดโปรเจกต์: ขนาดกลาง (Medium)

### ประมาณการความพยายาม
- **UFP × 8 ชม.** ≈ 904 ชั่วโมง
- **AFP × 8 ชม.** ≈ 832 ชั่วโมง
- **ทีมงาน 6 เดือน:** 3-4 คน

> **หมายเหตุ:** VAF = 0.92 หมายถึงระบบมีความซับซ้อนต่ำกว่าค่าเฉลี่ย (ค่าเฉลี่ย VAF = 1.0) ซึ่งสะท้อนว่าระบบ Rich Save ไม่ได้ซับซ้อนมากเกินไป มีรายละเอียดปรับลดลง ~8% จาก UFP
